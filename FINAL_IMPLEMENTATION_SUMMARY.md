## 🚀 QUICK START GUIDE

### Prerequisites
- Python 3.12+
- Node.js 24.13.1+
- Docker 29.2.1+
- Neo4j 5.17+

### 1. Start Neo4j

```powershell
docker run -d --name neo4j -p 7474:7474 -p 7687:7687 `
  -e NEO4J_AUTH=neo4j/password neo4j:5.17
```

### 2. Install Dependencies

```powershell
# Ocean Core
cd core\clisonix-ocean-core
pip install -r requirements.txt

# ASI Agents
cd ..\asi-agents
pip install -r requirements.txt

# AI V2
cd ..\ai-v2-neighborhood
pip install -r requirements.txt

# EuroWeb AGI
cd ..\euroweb-agi
pip install -r requirements.txt

# Labors
cd ..\clisonix-labors
pip install -r requirements.txt

# Orchestrator
cd ..\orchestrator
pip install -r requirements.txt

# Dashboard
cd ..\..\web\web-dashboard
npm install
```

### 3. Start Services (6 Terminals)

```powershell
# Terminal 1: Ocean Core (Port 7000)
cd core\clisonix-ocean-core
python ocean_core.py

# Terminal 2: ASI Agents (Port 7100)
cd core\asi-agents
python agents_registry.py

# Terminal 3: AI V2 (Port 7200)
cd core\ai-v2-neighborhood
python model_orchestration.py

# Terminal 4: EuroWeb AGI (Port 7300)
cd core\euroweb-agi
python thinking_engine.py

# Terminal 5: Labors (Port 7400)
cd core\clisonix-labors
python labor_units.py

# Terminal 6: Orchestrator (Port 8000 - MAIN)
cd core\orchestrator
python main.py
```

### 4. Start Dashboard

```powershell
# Terminal 7: Dashboard (Port 5173)
cd web\web-dashboard
npm run dev
```

### 5. Access

```
🌌 Orchestrator:   http://localhost:8000
🎯 Cwy Dashboard:  http://localhost:5173/cwy
📊 Swagger Docs:   http://localhost:8000/docs
```
